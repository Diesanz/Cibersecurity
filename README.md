# Cibersecurity – Resumen de proyectos

- EscaneoAutomatico (fsociety)
  - Menú interactivo en Python para lanzar escaneos con Nmap y ataques con Hydra desde una sola interfaz. Permite ajustar el comando antes de ejecutarlo.
  - Uso rápido: python EscaneoAutomatico/shell.py

- EscaneoExploitsVulnerabilidades
  - Script que verifica puertos, detecta servicios y versiones con Nmap y busca exploits relacionados usando searchsploit.
  - Uso rápido: python EscaneoExploitsVulnerabilidades/escaneo_puertos_vulnerabilidades.py

Requisitos mínimos (según el proyecto): Python 3, Nmap; opcionalmente Hydra y searchsploit.

Aviso legal: Utilizar solo en entornos controlados y con autorización expresa.
